## Notes on the two strongest finished competitors (studied live)

### Baton (Manufacturing) — https://github.com/Eternauts/baton
Industrial shift-handover safety "Control Room" dashboard. Notable patterns to match:
- **"CONFIRMED BY RULES (DETERMINISTIC)"** badge — AI output is confirmed by a deterministic rules
  layer, with a visible `guardrails: passed` + model/timestamp stamp (`gemini-3.5-flash`).
- Tabs: Overview · Living Architecture · Telemetry · **Audit Trail** · **Agent Trace**.
- "Audit persistence · Persisted · 10 ledger entries" (tamper-evidence story).
- Honest labeling: "simulated plant feed".
- Real-time: "Live · updated just now", gateway latency shown.

### AidAtlas (Social Impact) — https://github.com/sainathch45/aidatlas
Gemini crisis resource-allocation on a live map (Syria/Myanmar/India). Notable patterns:
- **Real data, stated loudly:** "LIVE DATA", HDX Humanitarian API, "Coordinates are real … not fabricated."
- **Grounded AI:** "Ask AidAtlas — Answers cite only real figures from the current allocation run —
  grounded, not invented." District detail shows real numbers + "Gemini's rationale".
- **Reusability as a technical claim:** "Two genuinely different real data shapes — proves the
  pipeline is reusable, not hardcoded to one crisis."
- **Full Google stack shown in footer:** Gemini · Firebase · Firestore · Cloud Run · BigQuery · Google Maps.

**Both win on:** visible grounding/verification + real data + polish + stack-flex.
**Neither touches QuickBite's core:** both are conventional *decision-support dashboards*; QuickBite's
disguised live two-way covert call is a different interaction paradigm with no equivalent in the field.
