# QuickBite demo video

Target length: under 3 minutes. Layout: phone on the left, dashboard on the right, subtitles in the top bar, callouts in the space under the dashboard.

| Part | File | Length |
|---|---|---|
| Opening | below | ~0:00–0:20 |
| Scene A: covert call, attacker breaking in, gunshot | [scene_a_covert_call.md](scene_a_covert_call.md) | ~0:20–1:35 |
| Scene B: car chase, shots fired, tyre blown, run to the police station | [scene_b_chase_call.md](scene_b_chase_call.md) | ~1:35–2:30 |
| Ending | below | ~2:30–2:50 |

Each scene file has the full ChatGPT role-play prompt, the sound-effect cues and the expected flow, with the dashboard callout for each moment.

**Who says what:**
- **Caller:** played by ChatGPT voice.
- **Mia:** the real QuickBite AI (Gemini Live). Her wording changes each take, so she's never scripted.
- **Sound operator:** plays the effects into the room so QuickBite hears them.
- **Callout:** on-screen text added in editing.

Record each call in full and cut the pauses in editing. Mark any time skip with a small "Later" label, so nothing looks faked.

## Before each take
- Resolve old test incidents so the new one is obvious in the Live queue.
- Turn off notifications on both machines. Keep the browser full screen with no tabs showing, and the phone fully charged.
- Test the setup for 20 seconds: ChatGPT voice and the sound effects should both show up in the Conversation and Seen & heard tiles.
- Start both recordings, then clap once near both machines to give a sync point.
